# 12V_PWM_Fan_Project
Project of 12V PWM fan control based on RiPico for Design Lab course


# 1. Design Goals
   
Main Project Goal
To design and implement a controller that allows for the speed control of 12 V fans using a Raspberry Pi Pico microcontroller and a PWM signal. The controller supports both local and remote control.

Control of at least one 12 V fan.
Ability to set the speed within the range of 0–100%.
Ability to set the speed using buttons.
Ability to set and display the speed via a terminal.
Design and 3D print the enclosure for the system.

# 2. Milestone
   
Milestone 1.
Define the functionality and select the necessary components for building the system.

Verification criteria:
    - Completed electrical schematic
    - List of necessary components.
	- List of planned functionalities.

Milestone 2.
Enabling the PWM port and one communication method

Verification criteria:
    - A functioning PWM port with the ability to control the duty cycle

Milestone 3. 
Starting the fans.

Verification criteria
	- 3 fans operational

Milestone 4. 
Add a second method for controlling the duty cycle

Verification method
    - Two methods for controlling the duty cycle operating in parallel

Milestone 5. 
Enclosure design
    

Verification method
    - Enclosure for the circuit board designed and printed
